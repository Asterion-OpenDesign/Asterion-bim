# ASTERION BIM

An open-source building information modelling (BIM) application, being built from scratch with a documented origin for every file.

> **Working name.** Legal availability of "ASTERION" as a trademark has not been confirmed.

## Status: bootstrap

This repository contains the project's foundations: licence, contribution rules, provenance policy, the automated gate that
enforces it, and CI. **It does not contain application code yet.** Code is added module by module, each with a specification
and a provenance entry ([docs/PROVENANCE_POLICY.md](docs/PROVENANCE_POLICY.md), [provenance/LEDGER.md](provenance/LEDGER.md)).

No feature, performance figure or file-format compatibility is claimed. When something is claimed, it will link to the test
that supports it.

## Goals

- A free, independent BIM application and engine.
- Interoperability with the file formats people already have, with published and reproducible coverage reports, and without
  claiming more than the tests demonstrate.
